# Captura la Bandera

> **Versión vigente:** `3.0.0`
>
> **Estado:** Cerrado.

Cada grupo construye su propio juego de captura la bandera, con el lenguaje y la
librería gráfica que quiera. La condición del curso es que **todas las
implementaciones puedan conectarse entre sí**: un cliente en Rust tiene que poder
jugar contra un servidor en Java. Para que eso funcione hace falta una
especificación común, y eso es lo que hay aquí.
